# 2. Полиномиальная регрессия. Регуляризация. Кросс-валидация.

## Задание

1. Реализуйте программно восстановление функциональной зависимости методом наименьших квадратов с помощью полиномиальной
регрессии. Для этого
* используйте значения параметра $M \in \{0, 1, . . . , 15\}$;
* генерируйте выборку двумя способами: в первом случае моделируйте ошибку измерения как равномерно распределённую случайную величину, во втором — как нормально распределённую случайную величину;
* генерируйте значения $x$ из заданного интервала случайно в соответствии с равномерным распределением;
* в качестве распознаваемых функциональных зависимостей используйте следующие:
	$y = \cos x, y = 5x^3 + x^2 + 5, y = x \sin x, x \in [0; 2 \pi]$
2. При условиях, сформулированных в задаче 1, реализуйте программно регуляризацию для полиномиальной регрессии и покажите, что переобучение может быть устранено при некоторых значениях $M$ и $\lambda$. Найдите эти значения для выбранных функций и некоторых выборок, полученных для этих функций.
3. Реализуйте программно кросс-валидацию для полиномиальной регрессии с регуляризацией. Определите наилучшую пару $(M, \lambda)$ для
восстановления функциональных зависимостей из задания 2.
