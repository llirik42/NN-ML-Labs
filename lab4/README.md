# 4. Многослойный перцептрон для решения задачи регрессии.

## Задание

Реализуйте программно восстановление функциональной зависимости с помощью многослойного перцептрона с одним и двумя слоями и количеством скрытых узлов в каждом из слоёв от одного до трёх. Для этого
* в качестве распознаваемых функциональных зависимостей используйте следующие: $y = \cos (2 \pi x), y = 5x^3 + x^2 + 5, y = x \sin (2 \pi x), x \in [0; 1]$
* cгенерируйте выборку, моделируя ошибку измерения как нормально распределённую случайную величину, и проведите процедуру кросс-валидации для определения наилучшего для распознавания количества слоёв и скрытых узлов в них.
