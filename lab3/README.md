# 3. Элементарный перцептрон. Ансамбль элементарных перцептронов.

## Задание

1. Реализуйте программно алгоритм обучения элементарного перцептрона для распознавания растровых изображений. Можете использовать следующие варианты реализации:
* 10 элементарных перцептронов, классифицирующих цифры как цифры двух классов: эта цифра/другая цифра;
* один перцептрон, вместо ступенчатой функции использующий в качестве функции активации функцию мягкого максимума, обучаемый с помощью стохастического градиентного спуска.
Может быть использована обучающая выборка для заданий 1 и 2 раздела «Метод ближайшего соседа».
2. Сформируйте ансамбль из обученных элементарных перцептронов из предыдущего задания. Сравните для одной и той же выборки результаты классификации растровых изображений с результатами, получеными методом ближайшего соседа и с помощью отдельного классификатора из предыдущего задания.
